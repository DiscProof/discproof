## Perfect Audio Copy

Create a plan and detailed prompt to build a Linux desktop application to replicate the functionality of an old Windows program called Exact Audio Copy (EAC). The primary use is ripping exact copies of music CDs and DVDs into FLAC format. The program would download metadata , such as track names and album cover art, for the music album from sources on the internet including GD3. The end result would be a folder for each album, containing a FLAC file for each song, a .jpg of the album cover art, and a log of the copy process. The files and metadata should be usable in music platforms such as Plex.

<br>

I want a sleek modern graphical interface that I can use on my Fedora KDE laptop.

<br>

See the file Exact Audio Copy (EAC).md for a description of how that program worked. 

<br>

Ask me any questions you need to create an application that has most of the performance of EAC in a clean modern linux application.
